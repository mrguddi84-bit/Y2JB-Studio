# Changelog

## Y2JB Studio v1.0 — first public release

- Introduces Y2JB Studio as an all-in-one PS5 homebrew manager for Windows.
- Adds a dashboard for PS5 connection diagnostics and FTP / ELF Loader status.
- Adds FTP Manager and Y2JB Manager workflows.
- Adds region detection, Y2JB file downloads, SHA-256 verification and guarded FTP transfers.
- Adds Theme Manager with PNG-based theme creation and a project library.
- Includes the Y2JB application name editor with backup safeguards.
- Provides a translated interface in German, English, Spanish, French and Portuguese.
- Ships as one portable Windows executable.
- Project owner reports successful final checks of FTP Manager, Y2JB Manager and YouTube PKG installation through Prospero Manager.
